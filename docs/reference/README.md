# Reference index

Durable, look-up-able knowledge — as opposed to [`docs/progress.md`](../progress.md),
which is a chronological journal of what happened. When something here would
also help a future session avoid re-discovering it the hard way, it belongs
in this folder, not just in the journal.

- [`modding-notes.md`](modding-notes.md) — Factorio Lua/RCON API behavior we've
  confirmed firsthand (what works, what doesn't, and why), independent of any
  particular game session.
- [`space-age-strategy.md`](space-age-strategy.md) — planet order, victory
  condition, gating tech, common mistakes. Sourced from a 101-agent
  deep-research pass (2026-07-24); space platform logistics and the
  Fulgora-vs-Gleba ordering debate are flagged as still-open.
- [`buildings.md`](buildings.md) — what each Space-Age-specific building
  actually does/needs, reference-table form. Currently covers only the four
  planets' signature buildings (Foundry, Electromagnetic Plant, Biochamber,
  Cryogenic Plant) — space platforms, elevated rails, quality/recycling, and
  agricultural towers still need their own research pass.
