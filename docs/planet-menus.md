# Planet Replicator menus (read-only analysis, 2026-11-14)

Each non-Nauvis planet gets a Replicator that serves only what is unique to it or what its Wheel makes in great plenty. Nauvis keeps the standard menu.

## Vulcanus
- Reachable from its own resources: 191 items
- **Unique** (Nauvis cannot make them from its own resources): **13**
  - machine `metallurgy`: 6: big-mining-drill, metallurgic-science-pack, tungsten-plate, turbo-splitter, turbo-transport-belt, turbo-underground-belt
  - machine `crafting`: 4: artillery-shell, artillery-turret, artillery-wagon, cliff-explosives
  - machine `crafting-with-fluid+metallurgy`: 1: foundry
  - machine `crafting+electromagnetics`: 1: speed-module-3
  - machine `crafting-with-fluid`: 1: tungsten-carbide
- **Also unique when Nauvis ships the basics** (needs this planet's resources plus Nauvis iron, copper, coal and so on): **0** more
- **Wheel mission item** `low-density-structure`: makeable from the planet's own resources
