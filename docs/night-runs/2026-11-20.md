  `OLLAMA_NUM_PARALLEL=1` and check before trusting the number.

## Found and fixed during the day
- **The game crashed when a player joined** (`Invalid name "state"`): a GUI child name collided with a LuaGuiElement
  property. Renamed `skippy_state`; the fake GUI now refuses colliding names. (81bf466)
- **`require` at runtime** in places.lua and world.lua: Factorio forbids it after control.lua is parsed, so
  `mark_place`, `places` and `find_placement{at}` failed live. Moved to load time; the test harness now enforces the rule.
  (36a49d4)
- **`build_now` left some pieces as ghosts:** trees marked for deconstruction under them. The result now says so
  (`waiting`). (36a49d4)
- **List parameters were `object` in the tool schema** (found by purple): its client would not send `plan_pieces` a
  list, so purple could build nothing all run. List params now become arrays. (27e75d5)
- **The leg crashed at prompt 17** on an arrow character: Windows' cp1252 console. The leg now writes UTF-8. (this commit)
- **Made-up craft times:** `lookup` gave a stone furnace's crafting speed with no recipe time, and the model said "one smelt
  every 0.5 s" and "120 plates a minute" (the real figure is 3.2 s per plate). Entity lookups now say how to get the time.
  (this commit)
